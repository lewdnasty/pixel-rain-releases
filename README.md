# Pixel Rain

A cascading rainbow of pixels: one pixel falls, then two, then a whole rainbow. Sand piles, water pools, fire burns, and it pulses to your music.

**[Download the latest version](https://github.com/lewdnasty/pixel-rain-releases/releases/latest)** for Windows, macOS or Linux. Each download is a small zip with just the app, a readme and the licence. Nothing to install, and your settings are kept between runs.

This repository only holds the downloads; the source isn't public. Every release lists what changed.

Made by lewdnasty.
